Entrar

Cómo entrar (una sola vez)

  1. Ejecuta servidor/supabase.sql entero en Supabase → SQL Editor.
  2. En Supabase → Authentication → Users → Add user → Create new user: tu email y una contraseña, con «Auto Confirm User» marcado.
  3. En el SQL Editor: insert into public.admins (id) select id from auth.users where email = 'TU_EMAIL';
  4. Entra aquí con ese email y esa contraseña.

Nadie más puede usar este panel: el servidor solo deja leer los informes y moderar el ranking a las cuentas de la tabla «admins».
